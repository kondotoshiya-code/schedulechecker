# ☁️ スケジュールチェッカー（クラウド版 / Google Apps Script）

パソコンに何もインストールせず、**ブラウザだけ**で動くクラウド版です。
指定した人のカレンダーを読み、今週・来週の予定を4カテゴリに仕分けして
**Google Chat に自動投稿**します。

> 詳しい操作は、Claudeがチャットで1ステップずつ案内します。
> このファイルは「全体像のメモ」として残してあります。

## 全体の流れ（全5ステップ）

1. **Apps Script プロジェクトを作る**（script.google.com）
2. **コードを貼り付ける**（`Code.gs` の中身をコピペ）
3. **Google Chat の Webhook を作る**→ URLをコードに貼る
4. **試しに1回実行**して動作確認（初回は許可ボタンを押す）
5. **自動実行をオン**にする（毎週月曜の朝に自動投稿）

## 設定できること（`Code.gs` の上のほう）

| 設定 | 内容 |
|---|---|
| `TARGET_CALENDARS` | チェックする人のメールアドレス |
| `INTERNAL_DOMAINS` | 自社とみなすドメイン |
| `WEEKS` | 期間（2 = 今週＋来週） |
| `CHAT_WEBHOOK_URL` | 投稿先 Google Chat の Webhook URL |

## 仕分けルール

- **●外部アポ**: 参加者に社外の人がいる、またはタイトルが外部アポ（訪問・商談など）
- **◎リモート外部アポ**: 上記のうちオンライン（Meet/Zoom等の語）
- **◯内部MTG**: 社外の人がおらず、自分以外の参加者がいる
- **それ以外**: 参加者なし・終日・個人ブロック等
