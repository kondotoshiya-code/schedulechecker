# 📅 スケジュールチェッカー

指定した人のGoogleカレンダーを読み取って、**今週・来週の予定**を
次の4つのカテゴリーに自動で仕分けするアプリです。

> ☁️ **クラウドで動かしたい方へ**: パソコンに何も入れず、ブラウザだけで動く
> **クラウド版（Google Apps Script）** もあります → [`apps-script/README_GAS.md`](apps-script/README_GAS.md)
> （結果を Google Chat に自動投稿できます）
>
> 以下はパソコン上で動かす **PC版（Python）** の説明です。

| 記号 | カテゴリー | 説明 |
|---|---|---|
| ● | 外部とのアポイント | 社外の相手とのアポ |
| ◎ | リモートの外部アポイント | 上記のうちオンライン実施のもの |
| ◯ | 内部ミーティング | 社内メンバー中心の打ち合わせ |
| （無印） | それ以外 | 終日・個人ブロックなど |

---

## 🧑‍💻 プログラミングが分からない方へ

このアプリを動かすには、最初の1回だけ準備が必要です。
**ゆっくり順番にやれば必ずできます。** 約15〜20分くらいです。

準備は大きく3ステップです。

1. **パソコンの準備**（Pythonを入れる）
2. **Googleの準備**（鍵ファイル `credentials.json` をもらう）
3. **アプリを動かす**

---

## ステップ1: パソコンの準備（Pythonを入れる）

1. [https://www.python.org/downloads/](https://www.python.org/downloads/) を開く
2. 大きな黄色いボタン「**Download Python**」を押してインストール
   - ⚠ Windowsの方は、インストール画面の最初で
     **「Add Python to PATH」にチェック**を入れてください（重要）
3. インストールが終わったら、次に進みます

---

## ステップ2: Googleの準備（鍵ファイルをもらう）

アプリがカレンダーを読むには、Googleから「鍵」をもらう必要があります。
画面が英語ですが、**書いてある通りにクリックするだけ**です。

### 2-1. プロジェクトを作る
1. [https://console.cloud.google.com/](https://console.cloud.google.com/) を開き、会社アカウントでログイン
2. 画面上部の「プロジェクトを選択」→「**新しいプロジェクト**」→ 名前は `schedule-checker` などでOK →「作成」

### 2-2. カレンダー機能をオンにする
1. 上の検索バーに「**Google Calendar API**」と入力して開く
2. 「**有効にする（Enable）**」ボタンを押す

### 2-3. 「同意画面」を作る
1. 左メニュー →「**APIとサービス**」→「**OAuth同意画面**」
2. User Type は「**内部（Internal）**」を選んで作成
   （※会社のGoogle Workspaceなら内部が選べます。選べなければ「外部」でOK）
3. アプリ名に `schedule-checker`、メールはあなたのアドレスを入れて保存して進む

### 2-4. 鍵ファイルを作ってダウンロード
1. 左メニュー →「**認証情報（Credentials）**」
2. 上の「**＋ 認証情報を作成**」→「**OAuth クライアント ID**」
3. アプリの種類で「**デスクトップアプリ（Desktop app）**」を選ぶ → 作成
4. 「**JSONをダウンロード**」を押す
5. ダウンロードしたファイルの**名前を `credentials.json` に変更**して、
   **このアプリのフォルダ（schedule_checker.py と同じ場所）に置く**

> 🔒 `credentials.json` と、あとで自動でできる `token.json` は
> **誰にも渡さない・どこにもアップロードしない**でください（あなた専用の鍵です）。
> このアプリは最初からアップロードされないように設定済みです。

---

## ステップ3: アプリを動かす

「**ターミナル**」（Windowsは「コマンドプロンプト」または「PowerShell」、Macは「ターミナル」）を開き、
このフォルダの中で次を順番に入力します。

### 3-1. 必要な部品を入れる（最初の1回だけ）
```
pip install -r requirements.txt
```

### 3-2. 実行する
```
python schedule_checker.py
```

- 初回はブラウザが自動で開きます → **会社アカウントでログイン** → 「**許可**」を押す
- 画面に予定の仕分け結果が表示されます！🎉
- 2回目以降はログイン不要で、すぐ結果が出ます

---

## ⚙️ 設定を変えたいとき

`schedule_checker.py` の上のほうにある「設定」を書き換えるだけです。

- **チェックする人を変える** → `TARGET_CALENDARS` のメールアドレスを編集
- **自社ドメインを足す** → `INTERNAL_DOMAINS` に追加
- **期間を変える** → `WEEKS = 2`（今週＋来週）の数字を変更

---

## ❓ うまくいかないとき

| 症状 | 対処 |
|---|---|
| `credentials.json が見つかりません` | ステップ2-4の鍵ファイルを、このフォルダに置いたか確認 |
| `このカレンダーを取得できませんでした` | その人があなたにカレンダーを共有しているか確認（閲覧権限） |
| `pip` や `python` が見つからない | ステップ1をやり直す（WindowsはPATHのチェックを忘れずに） |

困ったら、エラー文をそのまま私（Claude）に貼り付けて聞いてください。一緒に直します。
